Regrade — app map

One page in the browser, no server, no model. Follow one action, Generate 4 weeks, through the code:

StepWhereWhat happens
1src/main.ts → renderStageHead()The button's click handler calls generate(true).
2src/main.ts → generate()Calls generateBlock(bands, stats, played, teams, setup), stores the block in state, re-renders, announces the counters in the status region.
3src/scheduler.ts → chooseRounds()Per band, week by week: a backtracking search pairs every team once, avoiding pairings already played and pairing a team owed a home game with one owed an away game.
4src/scheduler.ts → generateBlock()Every pairing gets a venue, pitch and time from the slots the secretary set; hard constraints checked, preferences scored; fixtures that don't fit go to unscheduled with a reason.
5src/scheduler.ts → countConstraints()An independent recount of clashes, team clashes and the home/away gap; the same function the validate script uses.
6src/main.ts → renderGrid(), renderExport()One table per venue with the fixtures in slot order; the CSV preview and Download call toUploaderCsv() in src/export.ts.

A practice to reuse

Prove the kernel before the screen. The first slice was npm run validate: it seeds the league, generates a block and prints PASS or FAIL for every rule. It caught two real defects (4 repeat pairings and a home/away gap of 4) before any UI existed, and the fix is recorded in docs/adr/0002-matching-not-solver-library.md. Next time: write the PASS/FAIL script for the one thing that must be true, then build the screen that shows it.
