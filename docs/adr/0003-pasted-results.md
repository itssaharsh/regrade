# ADR 3: Results are pasted, not fetched

Status: accepted, 2026-09-26.

Context: the FA's Full-Time offers club-level fixture downloads and a spreadsheet uploader; no league-level results export or API was evidenced during research.

Decision: accept the uploader's own nine-column layout with scores filled in, or a simple five-column table, pasted into a textarea; name bad rows; load the good ones.

Consequence: usable today by any league; an import from a Full-Time download is a later enhancement once a real export is confirmed.
